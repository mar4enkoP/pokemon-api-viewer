# Pokemon API Viewer

A small frontend project that fetches Pokemon data from an external API, displays it in a table and allows users to manage selected items with `localStorage`.

The project was created as a learning project to practice JavaScript, API requests, DOM manipulation and basic client-side storage.

## Features

* Fetches Pokemon data from an external API
* Displays Pokemon information in a table
* Shows basic data such as name, height and weight
* Saves selected Pokemon in `localStorage`
* Allows users to remove saved Pokemon from the list
* Updates the page dynamically with JavaScript

## What I Learned

* Working with API requests
* Handling JSON data
* Rendering content dynamically with JavaScript
* Using `localStorage` for client-side data storage
* Updating the DOM based on user actions
* Structuring a small frontend project

## How to Run Locally

Clone the repository:

```bash
git clone https://github.com/mar4enkoP/pokemon-api-viewer.git
```

Open the project folder:

```bash
cd pokemon-api-viewer
```

Open `index.html` in your browser.

No installation is required.
